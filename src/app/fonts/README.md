The variable Latin WOFF2 files here are bundled locally so production builds do not fetch Google Fonts at build time. Each font's SIL Open Font License 1.1 is included in `licenses/`.

Source packages: `@fontsource-variable/{cormorant-garamond,inter,outfit,playfair-display,plus-jakarta-sans,space-grotesk,syne}`. Font files and licenses are unmodified.
